FRAME 完成版 v1.0

GitHub Pages用のローカル保存型プロットアプリです。
ZIPを解凍し、中の8ファイルをリポジトリ直下へアップロードしてください。

主な機能
- 作品一覧から複数の小説を一括管理
- 作品名検索
- 更新順／タイトル順／手動順の並べ替え
- 空白から新規作成／既存作品の丸ごと複製
- 作品一覧へ戻るボタン
- 固定REFERENCE HUD（人物／固定情報）
- 章ごとの開閉式プロット
- 複数章の同時展開
- 全章OPEN／CLOSE
- 春夏秋冬 × 朝昼夜の背景
- 作品単体／全作品のJSON書き出し
- 新旧FRAME JSONの読み込み
- 自動ローカル保存
- PWA対応
- アプリ内FRAMEロゴをそのまま使ったシンプルなアイコン

旧v0.1と同じURLへ上書きした場合、保存済みの1作品データは自動的に作品一覧へ移行します。
保存キー: frame-plot-v1


FINAL v1.1 追加:
- PLOT / REFERENCE の境界をドラッグして表示比率を変更
- 縦長表示では PLOT が上、REFERENCE が下
- 向きごとの表示比率を作品ごとに保存
- 章を開いている間は作品タイトルのヘッダーを自動圧縮
